AI-Powered SQL Data Analyst

Role: Full Stack AI Engineer
Tech: React, FastAPI, LangGraph
Year: 2025

A powerful AI-powered SQL analysis tool that democratizes data access by allowing non-technical users to query databases using plain English. By automating routine reporting ("How many users signed up last week?"), this tool frees up data scientists to focus on complex modeling rather than ad-hoc tickets.

View Code

The Problem

Non-technical managers constantly nag data teams for simple reports. This creates a bottleneck where executives rely on gut feelings because the "time-to-insight" is too long, and highly paid data scientists waste hours on basic SQL retrieval tasks.

This tool bridges that gap by providing a self-serve interface that translates natural language questions into safe, optimized SQL queries with instant visualization.

Key Capabilities

🗣️ Natural Language to SQL

Ask questions in plain English ("Show me top 5 products by revenue") and get syntactically correct SQL generated automatically.

📊 Auto-Visualization

The system doesn't just fetch data; it analyzes the result set and generates beautiful charts using Matplotlib without user configuration.

🛡️ 6-Layer Safety System

Comprehensive guardrails including Keyword Blocking (DROP, DELETE), Query Normalization, and Read-Only connection enforcement.

⚡ Real-Time Execution

Safely executes queries against SQLite databases with immediate feedback, reducing report turnaround from days to seconds.

🧠 Intelligent Validation

Advanced pattern matching detects suspicious SQL injection attempts and logic errors before execution.

🎨 Modern Architecture

Built with a React 18 + TypeScript frontend and a robust FastAPI + LangGraph backend for scalable agentic workflows.

Enterprise Safety Protocol

Security is the primary constraint for any database agent. This system implements a rigid multi-layer protection strategy to ensure Read-Only integrity.


🛡️ Active Guardrails

  • 1. Keyword Blocking: Automatically rejects DROP, DELETE, UPDATE, INSERT, ALTER.
  • 2. Pattern Detection: Identifies injection attempts via comments (--, /* */) and chained statements.
  • 3. Type Validation: Strictly enforces that every query must start with SELECT.
  • 4. Schema Awareness: Sanitizes all table and column names against the known schema to prevent identifier manipulation.

Under the Hood

The architecture decouples the reasoning engine from the execution environment.


Backend (Python):
• FastAPI: High-performance RESTful API server.
• LangGraph: Orchestrates the agent's reasoning loop (Plan → Query → Validate).
• SQLite: Read-only database connection.
• Matplotlib: Server-side image generation for consistency.


Frontend (React + TypeScript):
• Vite: Ultra-fast build tool.
• Axios: Handles asynchronous communication with the inference engine.
• Real-time UI: Displays SQL, Data Tables, and Charts simultaneously.
